# Groups

## Working Definitions

Starting with groups, we define a group $G$ to be a set endowed with a well-defined binary operation ($\cdot$) such that for $a, b, c \in G$ :

- It is associative i.e $(a\cdot b) \cdot c = a \cdot (b \cdot c)$. Thus henceforth we omit any brackets and we write $a \cdot b$ as $ab$.

- $\exists$ an identity element $e$ such that $ae = a = ea$ for all $a \in G$.

- Every element $x$ has an inverse denoted by $x^{-1}$ i.e. $xx^{-1} = e$.

Common (non-trivial) examples which you must be familiar with include the group of symmetries, for an n-gon it is called the [Dihedral groups](https://en.wikipedia.org/wiki/Dihedral_group) denoted by $D_{2n}$, [Symmetric group](https://en.wikipedia.org//wiki/Symmetric_group) $S_A$ for any set $A$ (i.e the group of bijections on A with composition operation).

For $a \in G$ where $G$ is a group, $|a|$ denotes the order of $a$ in $G$, i.e the smallest positive integer $k$ such that $a^k = e$. If $G$ is a finite group, then cardinality of $G$ is called the order of $G$, denoted by $|G|$.

For $A \subset G$ we say that $A$ generates subgroup $H$ of $G$ when the smallest subgroup of $G$ (a subgroup is a subset which is a group under the same operation as $G$, denoted by $H \leq G$) containing $A$ is $H$, this is denoted by $\langle A \rangle = H$. This is same as taking all multiplicative permutations of elements in $A$ and their inverses. This becomes clearer in section <a href="#group-presentations-and-free-groups" data-reference-type="ref" data-reference="group-presentations-and-free-groups">1.4</a>. For example $\langle\{1\}\rangle = \mathbb{Z}$. A group $G$ that can be generated by a single element $a$ is called cyclic, precisely because elements of $G$ will look like $\{e, a, a^2, a^3, ...\}$.

Let $G$ be any group. Following important subgroups are defined

- **Trivial subgroups** : $\{e\}$ and $G$

- **Center of G** : $Z(G) := \{a \in G : ax = xa \text{ } \forall x \in G\}$.

- **Centralizer of an element $a$** : $C(a) := \{ g \in G : ag = ga\}$

- **Centralizer of a subset $H$** : $C(H) := \{ g \in G : hg = gh \text{ } \forall h \in H\}$

- **Normalizer of a subset $H$** : $N(H) := \{ g \in G : gHg^{-1} = H, \text{ } \forall h \in H\}$.

- **Commutator Subgroup** : Denoted by $G'$ is the group $[G,G] := \langle A\rangle$ where $A := \{[x,y] := xyx^{-1}y^{-1} : x,y \in G\}$. The elements of $A$ are called commutators.

  
If $G$ is finite, the following are true:

1. Order of an element $a\in G$ divides $|G|$.

2. Order of a subgroup $H \leq G$ divides $|G|$.

3. If a prime $p$ divides $|G|$ then $G$ has a subgroup of order $p$.

 

Next we define a subgroup $H$ to be normal in $G$ denoted by $H \trianglelefteq G$ if for any $h \in H$ and $g \in G$, $ghg^{-1} \in H$. Thus $H \trianglelefteq G$ if for any $g \in G$, $gHg^{-1} = H$.

Let $G,H$ be groups. A function $F : G \longrightarrow H$ is called a group homomorphism if $F(xy) = F(x)F(y)$ for all $x,y \in G$. The kernel of $F$ is defined to be $\ker(F):= \{x \in G : F(x) = e_H\}$ and image of $F$ is defined as $\Im(F) := \{y \in H : \exists x\in G \text{ s.t. } y = F(x) \}$. For a group homomorphism $F$ as above, $\ker(F) \trianglelefteq G$ and $\Im(F) \leq H$.

**Examples :**

- $F : \mathbb{Z} \longrightarrow \mathbb{R}$ by $F(n) = n$ is an injective group homomorphism (also called an inclusion).

- $F_x : G \longrightarrow G$ by $F_x(g) = xgx^{-1}$ is a group isomorphism (i.e injective and surjective). Refer to section <a href="#conjugation-and-group-actions" data-reference-type="ref" data-reference="conjugation-and-group-actions">1.3</a> for details.

- $\mathbb{S}^1 \leq \mathbb{C} \setminus\{0\}$ is a subgroup of non-zero complex numbers w.r.t multiplication, and the inclusion map is a group homomorphism.

- $F : \mathbb{Z} \longrightarrow \mathbb{Z}$ by $F(n) = 2n$ is a group homomorphism.

## Quotients Groups and Isomorphism Theorems

Let $H \leq G$, then $G$ can be partitioned w.r.t $H$, in the sense that we can separate elements of $G$ into smaller subsets.
``` math
G = \bigsqcup\limits_{i \in \Lambda}{a_iH}
```
Above notation means $G$ can be written as some disjoint union of sets which look like $a_iH$. These are called left-cosets of $H$ in $G$. These are equivalence classes of the equivalence relation given by $g_1 \sim g_2$ if and only if $g_2^{-1}g_1 \in H$. One can consider a set of left-coset representatives i.e a set of representatives of the equivalences classes obtained above. If the equivalence classes are $`\mathcal{C} = \{ a_iH : i \in \Lambda
\}`$, then check that $\mathcal{C}$ forms a group with the binary operation $[g_1]*[g_2] = [g_1g_2]$ if and only if $H \trianglelefteq G$. The reader needs to check that the operation is well defined. This group $\mathcal{C}$ is denoted by $G/H$ and is called the factor group or the quotient group. If $\mathcal{C}$ is finite, its cardinality is called the index of $H$ in $G$, and is denoted by $| G : H|$ or $[G:H]$. 
The definition above is required to understand one of the most important theorems in group theory, called the **Isomorphism theorems**. They are as follows:

1. **First Isomorphism Theorem** : Let $\phi : G \longrightarrow H$ be a group homomorphism, then
 ``` math
 G/\ker(\phi) \simeq \Im(\phi)
 ```
 .

2. **Second Isomorphism Theorem**: If $H, K \leq G$ such that $H \leq N(K)$, then $HK \leq G, K\trianglelefteq HK, H \cap K \trianglelefteq H$ and
 ``` math
 HK/K \simeq H/{H\cap K}
 ```
 It is also called diamond isomorphism because of the following diagram:

 <div class="center">

 </div>

 In the above diagram, $HK/K \simeq H/{H\cap K}$, and $|HK : H| = |K : H\cap K|$.

3. **Third Isomorphism Theorem**: Let $H,K \trianglelefteq G$ with $H \leq K$. Then $K/H \trianglelefteq G/H$ and
 ``` math
 (G/H)/(K/H) \simeq G/K
 ```

4. **Fourth Isomorphism Theorem**: Let $K \trianglelefteq G$, then every subgroup of $G/K$ is of the form $A/K$ where $A \leq G$ is a subgroup of $G$ containing $K$.

## Conjugation and group actions

Take any set $X$ and an arbitrary group $G$. We say that $G$ acts on and $X$ denote it by $G\ \rotatebox[origin=c]{-140}{$\circlearrowright$} \text{ }X$ if we have a function $\sigma : G\times X \rightarrow{X}$ where $(g,x) \mapsto g\cdot x$ which satisfies :

- $e \cdot x = x$

- $g \cdot (h\cdot x) = (gh)\cdot x$

Let $x \in G$ be an element then for any $g \in G$, we call the element $gxg^{-1}$ a **conjugate** of $x$. One may note that a group can act on itself by conjugation. When $G \ \rotatebox[origin=c]{-140}{$\circlearrowright$} \text{ }X$ then it permutes the elements of X under influence of elements of G. Now when a group $G$ acts on itself with conjugation, for each $g \in G$ we get a permutation of elements of $G$ hence every element of $G$ corresponds to an automorphism of $G$. Thus we may take the group $\mathop{\mathrm{Aut}}(G)$ as the set of all automorphisms of G then set of maps corresponding to an element $g \in G$ is a subset of $\mathop{\mathrm{Aut}}(G)$. This turns out to be a subgroup called as the Inner Automorphism group of G denoted by $\mathop{\mathrm{Inn}}(G)$. So an element of $\mathop{\mathrm{Inn}}(G)$ is a map
``` math
\phi_g : G \rightarrow G \; |\; \phi_g(x) = gxg^{-1}
```
 

For a group action $\sigma : G \times X \longrightarrow X$ we define the following:

- For $x \in X$, the Orbit of $x$ is defined as $\mathop{\mathrm{Orb}}(x) :=\{g \cdot x \ | \ g \in G\}$

- For $x \in X$, the stabiliser of $x$ is defined as $\mathop{\mathrm{Stab}}(x) := \{ g \in G \ | \ g\cdot x = x\}$

 

The action is said to be **Faithful** if $(g\cdot x = x \ \forall x\in X) => (g = e)$. The action is said to be **Free** if all stabilizers are trivial, i.e if for every $x \in X$, $g \cdot x = x$ then $g = e$. The action is said to be **Transitive** if $\mathop{\mathrm{Orb}}(x) = X$ for all $x \in X$, equivalently, for every $x,y \in X$ there exists $g \in G$ such that $x = gy$.

## Group Presentations and Free Groups

Before we jump to free groups some things need to be formally defined. Although for a general idea, to understand a free group we want to start with a set called a basis say $X$ and then generate a group from elements of $X$.

The elements of $X = \{ x_1, x_2, \dots \}$ are treated as letters and expressions like $a_1a_2a_3\dots a_n$ are formed (set of words on X) and then a group structure is given by **juxtaposition** of words, i.e. for words $a$ and $b$ on X
``` math
a\cdot b = a_1a_2\dots a_kb_1b_2\dots b_j \text{ where } a = a_1a_2\dots a_k \text{ and } b = b_1b_2\dots b_j
```

Start with any set $X$, call it the set of **symbols**. Then take any set (denote it by $X^{-1}$) disjoint from $X$ and name the set $X \cup X^{-1}$ as the set of letters. A **word** $w$ in $X$ is an expression of the form $w = a_1a_2\dots a_k$ where each $a_i$ is a letter for $1 \leq i \leq k$. Elements of $X^{-1}$ are called inverses and for a bijection $\sigma : X \rightarrow X^{-1}$ we denote $\sigma(x) = x^{-1}$ as inverses of elements in X. For inverses of elements in $X^{-1}$ we take $\sigma^{-1}(x^{-1}) = x$. We will denote the ‘empty word’ by 1 which will be the identity for our operation juxtaposition[^1]. We define the length of a word to be k if $w = a_1a_2\dots a_k$, and length of empty word is 0. We say a word is **reduced** if $w = a_1a_2\dots a_k$ then for any $1 \leq i \leq k-1$, $a_i^{-1} \neq a_{i+1}$. A reduced word is called **cyclically reduced** if additionally we have $a_1^{-1} \neq a_{k}$.

One may note that subwords of reduced words are reduced and a word is cyclically reduced if and only if all its cyclic permutations are reduced (Ex.).

For a given word $w$ and $x\in X$ we define **deletion** of $xx^{-1}$ from $w$ by replacing $xx^{-1}$ by empty word 1 (we define **insertion** of $xx^{-1}$ in $w$ for replacing 1 with $xx^{-1}$). An **elementary reduction** of $w$ is deleting $xx^{-1}$ from a word $w$ for some $x \in X \cup X^{-1}$. A reduction is a finite sequence of elementary reductions such that if we start at $w$ and end at $w'$ then $w'$ is reduced word. Every reduction leads to a unique reduced word $w'$ for a particular word $w$.

Now consider a group $G$ and a generator set $X$. Then a word on $X$ determines a unique element in $G$ (although many words may give same element of the group). For example empty word 1 gives identity $e \in G$ and so does $xx^{-1}$.

<div class="sublemma">

**Lemma 1.1**. *Let $g \in G$ be an element and $X$ be a generator of $G$, then $\exists$ at least one reduced word $w$ on $X$ that represents $g$.*

</div>

Define the **length** of a word $l(g)$ to be the minimum of length of reduced words representing $g$.

For a group $G$ we want to write it in terms of a set of generators satisfying some conditions, so that the so obtained ‘group presentation’ highlights some important properties of the group. For this we define a word $w$ to be a relator if it represents identity $e \in G$ and the equation $w_1 = w_2$ a relation if the word $w_1w_2^{-1}$ is a relator. Relators 1 and $xx^{-1}$ are called trivial relators.

We can **derive** a word $w$ from a given set of words $W = \{w_1,w_2,\dots\}$ if $ww' = 0$ for some $w'$ generated by words in $W \cup (trivial \ relators)$.

**Presentation** of a group $G$ is a set of generators $X$ of $G$ and a set of relators (or relations) $R$ such that all possible relators (or relations) in $G$ can be derived from $R$. A group is called **finitely generated** (similarly **finitely related**) if $|X|$ (similarly $|R|$) is finite. If a group is both finitely generated and finitely related, we say it is **finitely presented**.

**Example :** Here are some presentations of $S_n$ and $D_{2n}$:

1. $S_3 = \langle p,q \ | \ p^2 = 1, \ q^2 = 1, \ (pq)^3 = 1\rangle$. Comparing this to the cycle notation of $S_3 = \{ e, \ (1 \ 2), \ (1 \ 3), \ (2 \ 3), \ (1 \ 2 \ 3), \ (1 \ 3 \ 2) \}$, one can choose $p = (1 \ 2)$ and $q = (2 \ 3)$, basically any pair of transpositions. More generally one can say
 ``` math
 S_n = \langle \sigma_1, \sigma_2, \dots, \sigma_{n-1} \ | \ \sigma_i^2 = 1, \ \sigma_i\sigma_j = \sigma_j\sigma_i\text{ for }|i-j|>1, \ (\sigma_i\sigma_{i+1})^3 = 1\rangle
 ```
 where $\sigma_i$ denotes the transposition $(i \ i+1)$.

2. $D_{2n} = \langle r,s \ | \ r^n = s^2 = (sr)^2 = 1\rangle$. Here $r, s$ denote rotation and a flip respectively.

Consider any group $G$ and take generator $X$ to be whole $G$. Then if we take the relators of length 3 (denote it by $\mathcal{R}_3$) then for any $R \in \mathcal{R}_3$ we have $R = abc$ where $a,b \in G$ and $c = (ab)^{-1}$. This gives a presentation for $G = \langle G\ | \mathcal{R}_3\rangle$. (One must try to confirm here that the defining relators should generate all possible relations in the group $G$).

For a given set of symbols $X$ and relators $R$, a presentation $\langle X \ | \ R \rangle$ defines a unique group (upto isomorphism). Start with basis $X$ and let $W(X)$ denote the set of all words on $X$. Next define equivalence relation on $W(X)$ where $w_1 \sim w_2$ if by insertion or deletion of words in $R$, their inverses or trivial relators we can transform $w_1$ to $w_2$. Then the cosests $W(x)/\sim$ forms a group with multiplication defined as
``` math
[w_1]\cdot[w_2] = [w_1w_2]
```

This motivates one to think that if we do not take any set of relators $R$ explicitly, obviously in the group the trivial relators are always present, so what group will be generaled if no extra relators are added while writing this presentation.

The answer lies in what we define as **Free Groups**. Thus a free group on a basis set $X$ is the group presented by $F(X) = \langle X \ | \ \mathcal{R_t} \rangle$ where $\mathcal{R_t}$ is the set which contains words generated by the trivial relators. If the generating set $X$ has order $n$ then we say the group $F(X)$ is free of rank $n$.

An alternate definition for a **free group** will be that $F$ is a free group on basis $X$ if $\phi$ is any function from set $X$ into a group $H$ then there exists a unique extension of $\phi$ into $H$.

## Automorphisms (examples)

This section is dedicated to introduce some small ideas regarding (group) automorphisms and finding $\mathop{\mathrm{Aut}}(G)$ for a group $G$. Note that there is no general way to find the automorphism group. Although one may try various approaches to determine where can the elements map to, so as to maintain the map to be a bijective homomorphism. The following may come handy :

1. A generating set maps to a generating set under any automorphism.

2. The order of an element in a group is preserved under the automorphism.

3. For group $G$ we always have a normal subgroup of $\mathop{\mathrm{Aut}}(G)$ i.e. the $\mathop{\mathrm{Inn}}(G)$ (refer to <a href="#conjugation-and-group-actions" data-reference-type="ref" data-reference="conjugation-and-group-actions">1.3</a> if unfamiliar). Moreover, $\mathop{\mathrm{Inn}}(G) \simeq G/Z(G)$ where $Z(G)$ is the center of $G$.

**The automorphism group $\mathop{\mathrm{Aut}}(\mathbb{Z})$ :** Consider a group $G$, then $\mathop{\mathrm{Aut}}(G)$ denotes the group of bijective homomorphisms from $G$ to itself. This has a group structure with the binary operation of composition of maps. As a simple example, $\mathop{\mathrm{Aut}}((\mathbb{Z}, +)) \simeq (\mathbb{Z}_2, +_2)$, because if a map $\phi$ is a homomorphism, then the images of generators will uniquely determine the whole map $\phi$, because it has to satisfy $\phi(a\cdot b) = \phi(a)\cdot\phi(b)$. Now $1 \in \mathbb{Z}$ is a generator and $\mathbb{Z}$ is cyclic, so 1 is the only generator, hence $\phi(1)$ determines the automorphism. Now for any $k$, $\phi(k) = \phi(1+1+\dots+1)$ ($k$ times) i.e. $k\phi(1)$. Now since the map is surjective, if $a$ maps to 1, then we can conclude that $\phi(1) = 1/a$ and thus it can only be +1 or -1. Thus $\phi(1) = 1$ generates an automorphism, and so does $\phi(1) = -1$. Since there are no other possible images for 1, these are the only two automorphisms of $\mathbb{Z}$. Moreover, one can see that $\mathop{\mathrm{Aut}}(\mathbb{Z}) \simeq \mathbb{Z}_2$ because apart from the identity map, for the map $\phi$ with $\phi(1) = -1$, we have $\phi^2 =$ identity.

**Automorphisms of $\mathbb{Z}_n$ :** We can carry a similar idea as above, i.e. of mapping generators to generators. For $\mathbb{Z}_n$, the numbers coprime to $n$ are generators. So the automorphism group will take our generator (say 1) to some other generator ($\varphi(n)$ choices, i.e. the Euler totient function). This gives the unitary group $U_n$ as our automorphism group.

**Automorphisms of $\mathbb{Z}_2 \times \mathbb{Z}_2$ :** This is not cyclic hence things are not as direct as above. Consider the direct product of $\mathbb{Z}_2$ with itself, this contains a total of 4 elements and we know that image of $(0,0)$ is fixed to be $(0,0)$. Now maximum number of possible maps is the number of ways we can shuffle the rest 3 elements, i.e. 3! = 6. It turns out that $\mathop{\mathrm{Aut}}(\mathbb{Z}_2 \times \mathbb{Z}_2) \simeq S_3$. This can be done by explicitly calculating, that adding any two distinct non-identity elements in $\mathbb{Z}_2 \times \mathbb{Z}_2$ you get the third non-identity element. Hence there are 6 distinct automorphisms. Moreover, one can consider a specific case and find that the automorphism group (under composition) turns out to be non-abelian, and conclude that the group must be $S_3$ (because the only non-abelian group of order 6 is $S_3$).

**Automorphisms of Dihedral group $D_{2n}$ :** The automorphism group of $D_{2n}$ can be computed by first trying to understand how the group itself looks. Note that $D_{2n} = \langle r,s \ | \ r^n = s^2 = (sr)^2 = 1\rangle$. Here $r, s$ denote rotation and a flip respectively. We need to check where these element can go under an automorphism. Cases $n=1,2$ are left as an exercise, for $n \geq 3$ we have the following lemma (refer [here](https://ysharifi.wordpress.com/2022/09/14/automorphisms-of-dihedral-groups/) for details):

<div class="lemma">

**Lemma 1.1**. *For $n \geq 3$,
``` math
\mathop{\mathrm{Aut}}(D_{2n}) = \{ f_{i,j} : i \in \{0,\dots,n-1\}, j \in \{1,\dots,n-1\}, \gcd(j,n) = 1\}
```
where
``` math
f_{i,j} : D_{2n} \longrightarrow D_{2n} \text{ is given by } f_{i,j}(r) = r^j, \text{ }f_{i,j}(s) = sr^i
```
.*

</div>

**Automorphisms of Infinite Dihedral group $D_{\infty}$ :** 
We have $D_{\infty} \simeq \mathbb{Z}_2*\mathbb{Z}_2$ i.e. the free product of $\mathbb{Z}_2$ with itself (refer to <a href="#free-product" data-reference-type="ref" data-reference="free-product">1.7</a> if unfamiliar). Turns out that the automorphism group of infinite dihedral group (or $\mathbb{Z}_2*\mathbb{Z}_2$) is
``` math
\mathop{\mathrm{Aut}}(\mathbb{Z}_2*\mathbb{Z}_2) \simeq (\mathbb{Z}_2*\mathbb{Z}_2) \rtimes_{\psi} \mathbb{Z}_2
```
for some function $\psi : \mathbb{Z}_2 \longrightarrow \mathop{\mathrm{Aut}}(\mathbb{Z}_2*\mathbb{Z}_2)$. (refer to [CGT_report](#CGT_report) )

## Free Product

Let $G = \langle X_1 | R_1\rangle$ and $H = \langle X_2 | R_2\rangle$ be two groups given as presentations where the generating sets $X_1$ and $X_2$ are disjoint. Then the free product of $G$ and $H$ is the group presented as $G*H = \langle X_1 \cup X_2 | R_1 \cup R_2 \rangle$. **Examples :**

1. Take the smallest non-trivial group $\mathbb{Z}/2\mathbb{Z}$ i.e $\mathbb{Z}_2$. Note that $\mathbb{Z}_2 = \langle a | a^2 = Id\rangle$. The group $\mathbb{Z}_2*\mathbb{Z}_2$ would look like $\langle a | a^2 = Id\rangle * \langle b | b^2 = Id\rangle$, since generating sets need to be disjoint, hence we get $\mathbb{Z}_2*\mathbb{Z}_2 = \langle a,b | a^2 = b^2 = Id\rangle$.

2. Take the groups $\mathbb{Z}_2$ and $\mathbb{Z}$ then their free product $\mathbb{Z}_2 * \mathbb{Z} := \langle a, b \ | \ a^2 = 1 \rangle$.

<div class="lemma">

**Lemma 1.2**. *There are natural inclusion maps from $G$ and $H$ to $G*H$ defined by the Identity function on respective generators of $G$ and $H$.*

</div>

**Proof :** Let us consider the generating sets $X_1$ of $G$ and $X_2$ of $H$. Take the canonical maps $\phi_1 : G \longrightarrow G*H$ and $\phi_2 : H \longrightarrow G*H$ which are extensions of maps $\phi_1^* : X_1 \longrightarrow G*H$ and $\phi_2^* : X_2 \longrightarrow G*H$ given by $\phi_1^*(x) = x$ for all $x \in X_1$, and similarly $\phi_2^*(y) = y$ for all $y \in X_2$. Then $\phi_1, \phi_2$ are the required inclusions. $\square$

<div class="lemma">

**Lemma 1.3**. *Free Product of any two non-trivial groups is always an infinite group.*

</div>

**Proof :** Let $G$ and $H$ be any two groups, let $a \in G$ and $b \in H$ be an element of the generators of $G$ and $H$ respectively where neither of $a, b$ is Identity. Note that the generators of $G$ and $H$ are disjoint, and no relator in $G$ or $H$ is a reduced word with both $a$ and $b$ in it, hence we have $\{(ab)^n | n\in \mathbb{N}\} \subseteq G*H$ is infinite, since $(ab)^n$ is always reduced. Moreover all elements of this set are distinct otherwise if $(ab)^n = (ab)^m$ then $(ab)^{m-n} = 1$ which again is a contradiction. $\square$

## Permutation group $S_n$

$S_n$ is the symmetric group of n elements i.e all bijections on n elements. This suggests that $|S_n| = n!$. The [cycle notation](https://en.wikipedia.org/wiki/Cyclic_permutation) will be used to work with these permutations, hence familiarity with the same is assumed.

**Facts :**

1. $S_n$ can be generated if we take all transpositions of the type $(i \ i+1)$ where $1\leq i \leq n-1$.
 ``` math
 S_n = \langle \sigma_1, \sigma_2, \dots, \sigma_{n-1} \ | \ \sigma_i^2 = 1, \ \sigma_i\sigma_j = \sigma_j\sigma_i\text{ for }|i-j|>1, \ (\sigma_i\sigma_{i+1})^3 = 1\rangle
 ```

2. $S_n$ can be generated by $\{(1 \ 2),(1 \ 2 \ \dots \ n)\}$.

3. Conjugation preserves cycle type, i.e. if we have a permutation $\phi$ and a permutation $\sigma = (a \ b \ c)$ then $\phi \ \sigma \ \phi^{-1} = (\phi(a) \ \phi(b) \ \phi(c))$

4. It is abelian (commutative) iff $n\leq 2$.

5. Solvable iff $n\leq 4$.

## (Useful) Exercises

1. For any group elements $a$ and $x$, prove that $|xax^{-1}| = |a|$.

2. For any group elements $a,b$, $|ab|=|ba|$.

3. Arbitrary intersection of subgroups of $G$ is a subgroup of $G$.

4. Let $G$ be an Abelian group and $H := \{x \in G \ | \ |x| \text{ is odd }\}$. Prove that $H$ is a subgroup of $G$.

5. Any group of even order must have odd number of elements of order 2.

6. Prove that the subset of elements of finite order in an Abelian group forms a subgroup. (This subgroup is called the **torsion subgroup**). Is the same thing true for non-Abelian groups?

7. Let $H \leq G$ and $G$ be finite. Suppose that $g\in G$ and n is the smallest positive integer such that $g^n \in H$. Prove that $n$ divides $|g|$.

8. Let $a$ belong to a group and $|a|$ = $m$. If $n$ is relatively prime to $m$, show that a can be written as the nth power of some element in the group.
